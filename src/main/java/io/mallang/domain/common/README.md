# Domain Common

여러 도메인 애그리거트에서 공유하는 Value Object, 인터페이스, 예외를 정의한다.

---

## 도메인 모델

### 수신자 (Receiver)
_Value Object_

#### 속성 & 규칙
| 속성 | 타입 | 규칙 |
|------|------|------|
| `name` | String | null·공백 불가 / 앞뒤 공백 없음 / 2자 이상 10자 이하 |
| `phoneNumber` | String | `010XXXXXXXX` 형식 |

---

### 주소 (Address)
_Value Object_

#### 속성 & 규칙
| 속성 | 타입 | 규칙 |
|------|------|------|
| `zipCode` | String | 5자리 숫자 / null 불가 |
| `mainAddress` | String | null·공백 불가 |
| `detailAddress` | String (nullable) | 상세주소 없음 허용 |

---

### 금액 (Money)
_Value Object_

#### 속성 & 규칙
| 속성 | 타입 | 규칙 |
|------|------|------|
| `amount` | int | 음수 불가 (0 허용 — 무료 상품) |

---

### IdGenerator
_Interface_

도메인 객체 생성 시 식별자를 채번한다. 애그리거트 루트와 엔티티 생성에 사용한다.

---

### ClockHolder
_Interface_

도메인 객체에서 현재 시각이 필요할 때 사용한다. 테스트에서 시각을 고정할 수 있도록 인터페이스로 추상화한다.

---

## 테스트 시나리오

### Receiver

- [x] 유효한 이름과 전화번호로 생성할 수 있다
- [x] 이름은 null 또는 공백이 아니어야 한다
- [x] 이름은 2자 이상 10자 이하여야 한다
- [x] 이름은 앞뒤 공백이 없어야 한다
- [x] 전화번호는 010XXXXXXXX 형식이어야 한다

### Address

- [x] 유효한 정보로 주소를 생성할 수 있다
- [x] 상세주소 없이 주소를 생성할 수 있다
- [x] 우편번호는 null이면 안 된다
- [x] 우편번호는 5자리 숫자여야 한다
- [x] 주소는 null 또는 공백이 아니어야 한다

### Money

- [x] 금액이 0 이상이면 정상 생성된다
- [x] 금액은 음수가 아니어야 한다
- [x] 두 금액을 더하면 합산된 금액이 반환된다
- [x] 금액을 더해도 원본 객체는 변하지 않는다
- [x] 금액에 수량을 곱하면 곱산된 금액이 반환된다
- [x] 금액을 곱해도 원본 객체는 변하지 않는다
